# Hina English レッスンアプリ

個人レッスンの生徒が使うアプリです。生徒ごとに、先生が中身を入れます。

| 生徒の画面 | 内容 |
| --- | --- |
| 単語カード | Week 1〜24 に分かれている。Week 1 は10語ずつ、Week 2 からは Day 1〜Day 7（1日14〜15語）。Day をえらぶと「単語」と「テスト」の2つのタブ。「単語」は単語の一覧で、どの単語からでもカードを開ける（カードは英語だけ → タップで意味と例文（日本語訳と解説つき）。下の「まえ」「一覧」「つぎ」で動ける）。「テスト」は4択のテストで、やりたいときにやる。「復習カードに入れる」のチェックつき。単語と例文の音声つき |
| 単語復習 | 「復習カードに入れる」にチェックした単語と、テストでまちがえた単語が入る。Level 1（単語を見て意味を自分でチェック）と Level 2（例文の空いているところに単語を書く）。どちらも順番はばらばら |
| フレーズ | スモールトークのコース（全員共通）。Week 1・2（Week ごとに Day 1〜7、1 日 7〜8 フレーズ）。まず場面と英語だけを見て、タップすると和訳・塊・解説が出る。そのあと、その塊を使った瞬間英作文（0〜2 問）を入力して答え合わせ（ヒントはボタンで）。Day ごとに 5 問のテスト。「復習タブに入れる」ボタンつき。音声つき |
| フレーズ復習 | 「復習タブに入れる」を押したフレーズと、テストでまちがえたフレーズが入る。フレーズが出たら、その場で同じ塊の瞬間英作文 |
| 今日のやること | ホームのいちばん上。毎日の「日記を書く」と「発音を1文 完了する」のうち、まだのものが出る。両方できると「全部できました」になる |
| 発音 | Month 1〜6 に分かれている（Month 1・Month 2 は全員共通で 30 文ずつ。Month 3 は先生が出した生徒だけ）。1日1文。お手本（先生の録音）を聞いて、自分の声を録音し、聞きなおせる。「完了」を押すと録音が先生に届く。次に開くと、まだ完了していない文から始まる。点数は出ない。日本語訳・発音のコツ（つなげて読むところ）・使う場面つき |
| 勉強時間 | アプリを開いて使っている時間が自動で記録される。アプリ以外で勉強した時間とメモは自分で記入でき、どちらも直せる。1週間（日ごと）・1か月（週ごと）・これまでの合計（月ごと）が見られる |
| 文法 | 単元（be動詞・時制・冠詞・現在完了形・接続詞・前置詞）→ レッスンを選ぶ。説明を読んで、すぐ問題を解きながら進む。例文の音声つき。先生が入れた「先生からの問題」もここ |
| 今週の勉強範囲 | ホームのいちばん上（今日のやることの上）。先生が生徒ごとに書く（生徒ごとのチャットか、先生ページの「設定・コード」から） |
| 授業メモ | 先生がレッスンのあとに届けるメモ（生徒ごと）。授業の日ごとに読める。「内容を元に復習する」で、メモの大事なフレーズが単語カードのように出る（英語 → タップで意味と解説）。「復習タブに入れる」でフレーズ復習へ |
| 日記 | 毎日「今日のお題」が出る（「前のお題」「次のお題」で何度でも変えられ、ひと回りすると最初にもどるので、とばしたお題にもまた戻れる）。英語で書いて送ると、先生に届く。AI 添削をオンにすると、送ったときに 1 回添削（説明は日本語。生徒の画面には「AI」とは出ません）。先生のコメントも表示 |

画面の左上の「‹」は 1 つ前の画面にもどります。単語カードやレッスンなど奥の画面では、右上の「ホーム」で、いっきにホームへもどれます。

先生ページでは、生徒の追加、教材の追加・編集、授業メモの公開、日記と AI 添削の確認、コメントの記入、発音の録音を聞くこと、勉強時間の確認ができます。画面はスマホにもパソコンにも合わせてあります。

- 生徒：`https://（アプリのURL）/` を開いて、レッスンコードを入れる
- 先生：`https://（アプリのURL）/teacher` を開いて、パスワードを入れる

## 生徒のスマホにアプリとして入れる

生徒の画面は、ホーム画面に追加すると、Safari や Chrome のバーが出ない「アプリ」として開けます（App Store からのインストールは不要）。

- 生徒がスマホのブラウザで開くと、ホームに「ホーム画面に追加しよう」のカードと手順が出ます（アプリとして開いているときは出ません。「閉じる」で消せて、いちばん下の「ホーム画面に追加する方法」でまた出せます）
- iPhone：Safari の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」。ホーム画面のアイコンから初めて開いたときは、もう一度レッスンコードを入れます（iPhone では、ホーム画面のアプリと Safari のログインが別々のため）
- Android：Chrome の「︙」→「ホーム画面に追加」（または「アプリをインストール」）。カードの「ホーム画面に追加する」ボタンからもできます。ログインはそのまま引きつがれます
- アイコンはオレンジに白の「Hi!」、名前は「Hina English」です（`public/icons/`、`public/manifest.webmanifest`）
- 録音（マイク）もアプリのまま使えます
- 先生ページ（`/teacher`）はアプリにはなりません。これまでどおりブラウザで開きます

## 公開する手順（最初の 1 回だけ）

Cloudflare は、GitHub のデフォルトブランチ（いまは `claude/english-phrases-matome-pdf-7pe8cd`）に入ったものを公開します。先にこの変更をそのブランチにマージしてください。

### 1. Cloudflare でアプリを作る

1. [dash.cloudflare.com](https://dash.cloudflare.com) で無料アカウントを作る
2. 「Workers & Pages」→「Create application」→「Import a repository」
3. GitHub をつないで、`hinakajisaki-dev/hina-english` を選ぶ
4. 設定をこうする
   - プロジェクト名：`hina-coaching`（`wrangler.jsonc` の `name` と同じにする。変えるときは両方変える）
   - ルートディレクトリ（Root directory / Path）：`lessons`
   - ビルドコマンド：空のまま
   - デプロイコマンド：`npx wrangler deploy`（最初から入っています）
   - 本番ブランチ（Production branch）：`claude/english-phrases-matome-pdf-7pe8cd`
5. 「Save and Deploy」。初回のデプロイで、データベース（D1 の `hina-lessons`）も自動で作られます

### 2. 先生ページのパスワードを入れる

1. できた Worker（`hina-coaching`）を開いて「Settings」→「Variables and Secrets」→「Add」
2. 種類は「Secret」、名前は `TEACHER_PASSWORD`、値は先生ページのパスワード（長めに。生徒には教えない）
3. 保存（Deploy）

### 3. 開いてみる

`https://hina-coaching.（あなたのアカウント名）.workers.dev/teacher` を開いて、パスワードでログインします。URL は Worker のページに表示されています。

Cloudflare の画面のボタン名は、変わることがあります。見つからないときは Claude に聞いてください。

## 生徒を追加する

1. 先生ページの「生徒を追加」に名前を入れる
2. 「招待メッセージをコピー」を押して、LINE などで生徒に送る（URL とレッスンコードが入っています）
3. 生徒は URL を開いて、コードを入れるだけ。一度入れば、次からは自動で入れます

レッスンコードだけをコピーするときは、先生ページのいちばん最初の画面（生徒の一覧）のそれぞれの生徒の「コードをコピー」か、生徒の「設定・コード」の「コードをコピー」を押します（ABCD-EFGH の形）。「全員のコードをまとめてコピー」を押すと、アプリの URL と全員の名前・コードが 1 回でコピーされます。

iPhone は Safari の共有ボタン →「ホーム画面に追加」で、アプリのようにアイコンから開けます。

コードを知られてしまったときは、生徒の「設定・コード」で「新しいコードにする」を押してください。古いコードは使えなくなります。

## 教材を入れる

生徒のページの各タブで、1 行に 1 つずつ入れます。区切りは `|` です。スプレッドシートの列をそのままコピーして貼りつけても大丈夫です。

| タブ | 1 行の書き方 | 例 |
| --- | --- | --- |
| 単語 | 単語 \| 意味 \| 例文（上の「Week をえらぶ」で週を選んでから追加） | `borrow \| 借りる \| Can I borrow your pen?` |
| 発音 | 読む文 \| コツ | `Three free throws. \| th は舌を軽くかむ` |
| 文法（先生からの問題） | 問題 \| 答え \| 選択肢 \| 解説 | `I ___ to Osaka. \| went \| go / went / gone \| 過去形` |
| 日記のテーマ | テーマ（入れると、その生徒の「今日のお題」はここから選ばれます。入れないときは、初心者向けのお題 45 個から） | `週末にしたこと` |

- 例文・メモ・コツ・選択肢・解説は、なくても大丈夫です
- 文法の問題の空欄は `___`（アンダーバー 2 つ以上）。選択肢は `/` で区切ります。選択肢がないと、生徒が答えを入力する問題になります
- 「今日のテーマ」は、毎日リストの中から順番に変わります
- 単語は、タブの上の「Week をえらぶ」で週（Week 1〜24）を選んでから追加します。一覧も、選んだ週の単語だけが出ます。生徒の画面では、単語がある週だけ開けます
- Week 1 には全員共通の単語帳（100 語）が入っています（下の「単語帳と復習」）。先生ページで足した単語は、その生徒の週の最後に加わります

## 生徒ごとのチャット

先生は、生徒1人に1つ Claude のチャットを持ち、その生徒だけの授業メモ・単語・発音・文法の問題・日記のテーマを、チャットからアプリに直接入れられます（`scripts/teacher.mjs`）。はじめの設定（Worker のシークレット `TEACHER_API_TOKEN` と、Claude の環境の `HINA_TEACHER_TOKEN`・ネットワーク）と使い方は `docs/student-chats.md`。

## エラーの記録とエラー係のチャット

日記の添削ができなかった、🔊 の音声を作れなかった、サーバーや画面（生徒の画面・先生ページ）でエラーが起きた、といったことは、アプリのデータベースに記録されます。送って 10 分たっても添削がない日記も、エラーとして出ます。Claude のチャットを1つ「エラー係」にしておくと、1時間に1回これを見て、日記の添削のやり直しなど直せるものはその場で直し、先生に知らせます（キーやクレジットなど、先生がすることがあるときも）。コマンドと、エラー係がすることは `docs/error-chat.md`。

## 過去の日記を入れる

アプリを使う前に書いていた日記は、生徒ごとのチャットから、その日付のまま入れられます（`journals` コマンド。書き方は `docs/student-chats.md`）。

- AI の添削はしません。生徒の画面にも「添削してもらう」ボタンは出ません
- 日記の一覧には日付の新しい順に並びます。先生ページでは「過去の日記」と出て、未読にはなりません
- 同じ日・同じ本文の日記がもうあるときは、とばします（同じファイルを2回入れても増えません）

## 過去の勉強時間を入れる

アプリを使う前の勉強時間（スプレッドシートの1日の合計など）は、生徒ごとのチャットから、日ごとに入れられます（`study-days` コマンド。書き方は `docs/student-chats.md`）。

- 「アプリ以外の勉強」の分として入ります。アプリの時間はふえません。生徒の画面と先生ページの勉強時間のグラフ（月のグラフで「‹ 前」）に出ます
- その日にもう記録があるとき（アプリを使った日や、生徒が自分で書いた日）は、とばします（同じファイルを2回入れても増えません）。`--replace` で上書きもできます
- まちがえたときは `--undo` でもどせます

## 生徒の画面に出すもの

生徒ごとに、ホームに出すものを選べます（今週の勉強範囲・日記・単語カード・単語復習・フレーズ・フレーズ復習・文法・発音課題・授業メモ・勉強時間）。先生ページの生徒の「設定・コード」→「生徒の画面に出すもの」のチェックか、生徒ごとのチャット（`menu` コマンド）で変えます。

- 出さないものは、ホームのボタンが消え、その画面を開いても（ブックマークなど）ホームにもどります
- 日記と発音課題を出さない生徒には、「今日のやること」にもその分が出ません（両方出さないと「今日のやること」ごと消えます）
- 横に2つ並ぶボタンの片方が消えたときは、残ったほうが横いっぱいになります
- はじめは全部出ます。あとから足した項目も、出さない設定にするまでは全員に出ます

## 授業メモ

くわしくは `docs/lesson-notes.md`。

- 生徒に見せるかどうかは `public/course.js` の `NOTES_FOR_STUDENTS`（いまは `true`）。`false` にすると、公開したメモも生徒のホームと API に出なくなります（先生ページとチャットからは、そのまま入れたり公開したりできます）

- 授業中の Google ドキュメントのメモを、その生徒用の Claude のチャット（「〇〇さん」）で整理して、チャットからアプリに入れます。先生ページの生徒の「授業メモ」タブに貼っても入れられます
- 授業の日・タイトル（なくてもOK）・本文を入れて、「プレビュー」で生徒の画面と同じ見た目と、復習カードの一覧を確認できます
- 「下書き保存」は先生だけに見えます。「保存して公開する」か、一覧の「公開する」で生徒に届きます。「公開をやめる」で生徒の画面から消えます。公開中のメモを直すと、そのまま生徒の画面も変わります
- 生徒の画面：ホームの「📝 授業メモ」（勉強時間の上）→ これまでの授業の一覧（1. 8月3日（月）、2. 8月16日（日）… と古い順に番号つき）→ メモがある授業はタップでメモ。メモは「## 」のまとまりごとに 1 ページずつ出ます（上に「2 / 5」のような進み具合、下に「前へ」「次へ」。メモを開き直すと、前に見ていたページから）。ページの上には「大事なポイント」（`**ポイント**`）の箱と、答えと説明が見えている例（`**例**`）。英文の一部を青・赤の文字にもできます（`{青:until}` `{赤:I graduated}`。つなぎの言葉は青、そのあとの主語＋動詞は赤）。英作文（`**問題**`・`**答え**`）は日本語だけのカードになり、英語で言ってみてからタップすると、答え（🔊）・ほかの言い方・ポイントが出ます。英文（`**英語**`・`**意味**`）はその反対で、英語（🔊）だけのカードになり、「タップして日本語を見る」で、日本語・ほかの言い方・ポイントが出ます（長い英作文は 1 文ずつのカードに）。最後のページから「内容を元に復習する」へ進めます（1 ページ目にも「復習問題だけする」）。いちばん最後の「## 復習問題」の表は、表としては出ずに「内容を元に復習する（〇こ）」ボタンになります。画面の下に単語カードのように 1 枚ずつ出るので、メモを読みながら見られます。カードは 3 つの形があり、1 つのメモにまぜられます（表の列の名前で決まる。書き方は `docs/lesson-notes.md`）
  - ふつうのカード `| 英語 | 意味 | 解説 |`：英語と 🔊 → タップで意味と解説
  - 瞬間英作文 `| 日本語 | 答え | ポイント |`：日本語 → タップで英語（🔊）とポイント
  - 並び替え `| 日本語 | ならべる単語 | 答え |`：日本語と、ばらばらの単語 → タップで正しい英文（🔊）
- カードの「復習タブに入れる」で、そのカードがフレーズ復習に入ります（フレーズ復習では「📝 10月12日の授業」と出て、英文と意味のカードだけで、フレーズのような復習テストはなし）。授業メモは生徒ごとなので、どの生徒も自分のメモのカードだけです
- これまでの授業の一覧は、授業メモのある日（下書きもふくむ。今日まで）と、メモのない授業の日です。メモのない授業の日（アプリの前の授業など）は、生徒ごとのチャットの `lesson-days` で入れます（`docs/student-chats.md`）。番号は古い日から 1, 2, 3 … とつきます。ホームの授業メモには「これまでの授業 〇 回」と出ます。先生ページの「授業メモ」タブにも同じ一覧が出ます

## 単語帳と復習

単語帳は、ふだんは生徒全員に共通です。中身は `public/vocab/week1.js`（先生のスライド「単語帳 week 1」から。100 語・例文 200）。Week ごとに、生徒によって別の単語帳を出すこともできます（下の「生徒ごとの単語帳」）。

- Week 1 の単語は 10 語ずつのセット（10 セット）に分かれています。Week 2 からは、単語帳の 100 語が Day 1〜Day 7 に分かれます（Day 1・2 は 15 語、Day 3〜7 は 14 語。その生徒に先生が足した単語は最後の日たちに加わる）。カードで 1 語ずつ「単語・意味・例文 2 つ（日本語訳と解説）」を見て、セット（その日）の最後に 4 択のテスト（単語の意味を選ぶ）
- テストでまちがえた単語は、自動で「復習」に入ります。カードの「復習カードに入れる」にチェックした単語も入ります。チェックを外すか、復習の画面で「外す」を押すと出ます
- 復習の Level 1：単語（と例文 1 つ）を見て、「単語の意味と例文を頭の中で言えるか」確かめてから「意味を見る」→「わかった / わからなかった」を自分で押す
- 復習の Level 2：日本語訳を見て、例文の空いているところに単語を書く。「ヒントを見る」を押すと、最初の文字と文字数が出ます（答えの単語そのものは出ません）。元の形（make）を書いて文の形（made）とちがうときは「おしい！」
- 1 回の復習は 20 語まで。終わったら、わかった（正解した）単語の中から、復習カードから外す単語と残す単語をチェックで選べます
- 先生ページの生徒の「単語」タブで、セットごとのテスト結果と、復習カードの数が見られます
- 単語カードとフレーズは、セットの途中でやめても、つづきから始められます（アプリを閉じても）。フレーズは、次に開くとやめたところから。単語カードは、Day の一覧でやめた単語に「つづき」が出ます。いちばん新しいものは、一覧のいちばん上の「▶ つづきから」からも開けます。場所は生徒のスマホに保存されるので、別のスマホでは最初からです。単語カードは最後のカードで「おわり」を押すと、フレーズは最後まで進めてテストへ行くと、つづきからは消えます
- Week 2 からも同じ形で作れます。スライドのリンクを Claude に渡してください

### 生徒ごとの単語帳

Week ごとに、全員共通の単語帳のかわりに、別の単語帳を出せます（先生ページの生徒の「設定・コード」→「単語帳」、または生徒ごとのチャットの `vocab-books` コマンド）。

- いまある別の単語帳：
  - `ielts1`「IELTS 語彙 Week 1」（`public/vocab/ielts1.js`。先生の PDF「IELTS 語彙 100」から。10 のテーマ × 10 語、例文は 1 語に 1 つ）
  - `ielts2`「IELTS 語彙 Week 2」（`public/vocab/ielts2.js`。はるきさんのチャットで先生が OK した 100 語。10 のテーマ × 10 語、例文は 1 語に 1 つ）
  - `linkup1`「LinkUp 英単語 Week 1」（`public/vocab/linkup1.js`。先生の PDF「LinkUp英単語」の最初の 10 ページから。動詞 30・名詞 20・形容詞 20・副詞 10・前置詞 20 の 100 語、例文は 1 語に 1 つ（日本語訳つき）。PDF の発音記号は入れていない）
  - `w2`〜`w6`「単語帳 Week 2〜6」（`public/vocab/week2.js`〜`week6.js`。先生のスライド「単語帳 week 2〜6」から。100 語・例文 200 ずつ）。Week 1 のつづきですが、いまは全員共通ではなく、出した生徒だけに出ます（`everyone: false`。全員に出すときは、その行を消す）
- 単語帳がない Week（たとえば Week 2 で、その生徒に `w2` を出していない）は、生徒の画面で「まだありません」
- 別の単語帳にした生徒には、その Week の全員共通の単語帳は出ません。ほかの生徒は変わりません
- カード・テスト・復習・音声は、全員共通の単語帳と同じです。テストの結果と復習カードは単語帳ごとに残るので、もとにもどすと、前の記録がまた出ます
- 新しい単語帳（たとえば IELTS の Week 2）は、PDF やスライドを Claude に渡すと作れます。作ったあと、出したい生徒に `vocab-books` で設定します

## フレーズとフレーズ復習

フレーズは、単語帳と同じく生徒全員に共通です。中身はスモールトークのコースで、`public/phrases/` に週ごとのファイル（`week1.js` …）で入っています。

- いま入っているのは 2 週分。もとはこのリポジトリの `smalltalk/week1.md`・`week2.md`（書き方のルールは `smalltalk/README.md`）
  - Week 1「はじめて会った人と話す」：#1〜49 の 49 フレーズ、1 日 7 フレーズ × Day 1〜7、瞬間英作文 92 問
  - Week 2「話題を広げて、気持ちよく会話を終える」：#50〜100 の 51 フレーズ、Day 1〜5 は 7 フレーズ・Day 6〜7 は 8 フレーズ、瞬間英作文 96 問
- ホームの順番：今週の勉強範囲 → 今日のやること → 日記 → 単語カード・単語復習 → フレーズ・フレーズ復習 → 文法・発音課題 → 授業メモ → 勉強時間
- ホームと先生ページの進み具合は、単語とフレーズは「いまの週」の分だけ（テストが何セット終わったか）、発音は「いま取り組んでいる Month」の分だけで数えます。いまの週は `public/course.js` の `CURRENT_WEEK`（いまは 1）。Week 2 に進むときは、ここを 2 にします（ほかの週も、ふだんどおり開けます）。発音の Month は、前の Month を全部完了すると自動で次に進みます
- 1 フレーズの流れ：番号（#1〜）・場面と英語のフレーズ（🔊つき）→ タップか「次へ」で和訳・塊・解説（・例文）→ もう一度「次へ」で「瞬間英作文」0〜2 問（日本語を見て英語を入力）。「次へ」を押しても、解説を見ないまま問題には進みません
- 答え方の例になっているフレーズには「💬 返答例」と、どのフレーズへの返答か（「Hi! How's it going?」（#1）への返答例）が出ます。どれが返答例かは `scripts/smalltalk-overrides.json` で決めています（Week 1 は 24、Week 2 は 18）
- 和訳は、長さに合わせて文字の大きさを変え、いつも 1 行に収まります
- 塊は 1 つの形を 1 行に書き、カードでも「ヒントを見る」でも、その行のまま改行して出ます
- 塊の下に「塊の意味」（『〜はどう？』と様子を聞く形 / What about you? も同じ意味 など）が出ます。解説には使い方だけを書きます
- 解説の下に例文（英語と和訳、🔊つき）が出ます
- 画面の上に「📖 フレーズを覚えよう」「✏️ 瞬間英作文 1 / 2」（フレーズ復習では「✏️ 復習テスト」）と出るので、いまカードなのか問題なのかがわかります
- ヒント（塊と、問題ごとのヒント）は「ヒントを見る」を押したときだけ出ます。教材の答えと合わないときは、文法の問題と同じように AI が判定します（ほかの正しい言い方なら ⭕。まちがいなら「スペルミス」「文法」などを指摘して理由を説明）。「正解を聞く」で正解の音声
- カードの「復習タブに入れる」ボタンで、フレーズ復習に入れたり外したりできます
- Day の最後にテスト（その日の瞬間英作文から 5 問、順番はばらばら）。「ヒントを見る」で塊とヒントが出ます（カードのあとの瞬間英作文も同じ）。まちがえたフレーズは、自動でフレーズ復習に入ります
- フレーズ復習：1 回 10 フレーズまで。フレーズのカード（タップで和訳・塊・解説）のあと、その場で同じ塊の瞬間英作文。終わったら、外すフレーズをチェックで選べます（瞬間英作文が全部正解だったものには、はじめからチェック）
- 先生ページの生徒の「フレーズ」タブで、Day ごとのテスト結果と、フレーズ復習の数が見られます
- 以前の「今日のフレーズ」（先生が生徒ごとに入れるフレーズ）はなくなりました
- md を直したら、アプリのデータを作りなおします（`cd lessons` してから `node scripts/smalltalk-to-js.mjs ../smalltalk/week1.md 1 "smalltalk/week1.md" > public/phrases/week1.js`。Week 2 も同じ）。`public/phrases/weekN.js` は手で直しません
- md にない変更（Week 1 の「場面1：あいさつ」から「（ホテルのプールで）」を外す、返答例）は `scripts/smalltalk-overrides.json` にあり、作りなおしても消えません
- Week 3 からも、`smalltalk/README.md` の書き方の md ファイルがあれば、そのまま入れられます。Claude に頼んでください

## 文法の単元とレッスン

文法の単元とレッスンは、生徒全員に共通です。中身は `public/grammar/` に、単元ごとのファイルで書いてあります（`be.js`・`tense.js`・`articles.js`・`perfect.js`・`conjunctions.js`・`prepositions.js`。並び順は `lessons.js`）。どれも先生の「中学文法」ドキュメントの同じ名前の章をもとにしています。

初めて習う生徒が置いていかれないように、説明はどのレッスンも同じ作りです：

- 1画面に1つのことだけ。文章は1〜2文
- 「ふつうの文 ↓ 変えた文」を見比べるカード（英文ごとに日本語訳と音声つき）と、覚えることを1〜2行だけ大きく
- 説明の例文は、すぐあとの問題とは別の文にする（同じ文を答えるだけにならないように）
- 色分け：**赤**＝形が変わるところ（He / She と s、am / is / are、ing、ed、will、a / an / the など）、**青**＝「いつ・どのくらい」を表す言葉（always、now、yesterday、tomorrow など）。現在完了形は have / has と過去分詞が赤、ever / just / for などが青。接続詞は授業メモと同じく、つなぎの言葉が青・そのあとの主語＋動詞が赤。前置詞は前置詞が赤
- 日本語は「、」「。」「：」のまとまりで改行する（`student.js` の `phrased()`）。ヒント・まとめの箱は `\n` で1行ずつ。スマホの幅（390・375）で、1文字だけ次の行に残らないかを確かめる
- 説明のあとすぐに、2〜3問ずつ解く。「まとめ」画面はなし

| 単元 | レッスン | 問題数 |
| --- | --- | --- |
| 1. be動詞 | am / is / are、was / were | 15・9 |
| 2. 時制 | 現在形、現在進行形、過去形、未来形、時制のまとめ | 16・16・14・11・11 |
| 3. 冠詞 | a / an と the、数えられない名詞・冠詞なし | 13・12 |

前置詞は、テーマ（📍場所・📦位置・➡️方向・🕒時間・🚃方法・相手）を選ぶ形です。カードにはテーマの名前と、習う前置詞（赤）が出ます。最後の「🔀 まぜて練習」は、5つのテーマの問題（各テーマの最後の選ぶ問題 2 問と英作文 1 問）をテーマが入れかわる順に出します（15 問）。

ドキュメントにあるけれど、シンプルにするために外したもの：

- 現在形の一般動詞の否定文・疑問文（do / does）
- 時制の「総合練習」の過去進行形の3問（(4)(9)(14)。過去進行形のレッスンがまだないため）と、(11)「彼はいつも朝食を食べません」
- 未来形の練習 (5)「あなたは今夜、夕食を作る予定ですか？」
- 冠詞の「同じ単語でも意味で変わる」（paper / chicken）と、練習問題 (14)「昔の友達の1人」

ドキュメントにない説明を足したところ：

- 現在進行形の「ing のつけ方」（ドキュメントの 3-2 が抜けていたため）
- 冠詞の練習問題 (8) I like dogs. の解説（「〜というもの全体」は複数形で冠詞なし）
- 各レッスンの、ドキュメントにない練習問題（はじめの簡単な並べかえ、使い分けを確かめる選ぶ問題など）

それから：

- 生徒ごとの結果（ベスト・前回・回数）は、先生ページの生徒の「文法」タブで見られます
- 英語を入力する問題でまちがえると、どこがちがうかを 1 つずつ出します。「スペルミス」（eveyy → every）、「文法」（like → likes（s をつける）、buyed → bought（buy の過去形は bought）、is → are（be動詞））、「いらない単語」「たりない単語」「語順」に分けて、生徒の答えにも印をつけます。スペルミスだけのときは「おしい！」と出ます。先生からの問題（入力する問題）も同じです
- 答えが一通りとは限らないので、AI 添削を使っているときは、教材の答えと合わなかった答えを AI が判定します（「答えを判定中…」と出て、数秒〜10 秒ほど）。意味が合っていて、文法的に正しく、練習している塊や文法を使っていれば、言い方がちがっても「⭕ これもOK！」になり、点数にも入ります。少しぎこちない・ネイティブはあまり言わない言い方でも、文法が合っていれば OK です（例：The hat is great by the way →「ネイティブは By the way, I love your hat. のように言うことが多いです」と、教材の答えも表示）。問題ごとのヒント（「I love your 〜」など）は使わなくても大丈夫です。スペルミスや文法のまちがいがあるとき、意味が変わるとき、練習している塊を使っていないときは ❌ です
- ❌ のときは、AI が「なぜダメか」を 1 つずつ書き足します。例：「文法・前置詞　in → at　「家に」は at home と言います。in は使いません」。AI はまちがいの種類も見直します（childs → children は「文法・複数形」）
- AI がエラーのとき（または 1 日の上限のとき）は、これまでどおり教材の答えだけで判定します
- 新しいレッスンや単元を足したいとき、説明や問題を直したいときは、Claude に頼んでください。もとになるドキュメントがあれば、そのリンクを渡すと作れます

## AI 添削を使う（あとからでOK）

API キーを入れると、そのあとに送られた日記から、AI が 1 回ずつ添削します。キーを入れる前に送られた日記は、生徒の画面の「添削してもらう」ボタンで 1 回だけ添削できます。

1. [console.anthropic.com](https://console.anthropic.com) にログイン
2. 「Billing」でクレジットを購入（まずは $10 ほどで十分です）
3. 「Limits」で、月の使用上限を設定（例：$15）
4. 「API Keys」→「Create Key」でキーを作り、コピーする（一度しか表示されません）
5. Cloudflare の Worker（`hina-coaching`）で「Settings」→「Variables and Secrets」→「Add」。種類は「Secret」、名前は `ANTHROPIC_API_KEY`、値はコピーしたキー。保存（Deploy）

やめたいときは、`ANTHROPIC_API_KEY` を削除すれば、また日記が先生にだけ届く形にもどります。

## AI 添削について

- 先生ページの「設定・コード」にある「AI へのメモ」で、生徒ごとに「何を直して、何を直さないか」を決められます。メモは AI の基本ルールより優先されます。生徒には見えません
  - 例：「英検 3 級くらい。過去形と現在完了だけ重点的に直す」「冠詞（a / the）は直さない」「直すのは 3 つまで」「説明は短く、やさしい言葉で」
- 全員に共通の基本ルール（文法・単語の選び方・不自然な言い方を直す、生徒の言いたいことは変えない、直したところは最大 8 つ、説明は日本語）は `src/ai.js` に書いてあります。変えたいときは Claude に頼んでください
- 添削は中学文法の範囲で、シンプルな直し方にします
- スペルミスは、添削した日記の中で、正しいつづりを青い字で見せるだけです。「直したところ」には出さず、説明もつけません（前に添削した日記も、同じように見えます）。先生ページも同じです
- 句読点（カンマ・ピリオド・コロン・ハイフンなど）は直しません。AI が句読点だけの直しを返しても、生徒にも先生にも出ないようにしています（添削した日記の中でも、句読点は生徒が書いたまま）
- 使う AI は `wrangler.jsonc` の `AI_MODEL` です。いまは一番かしこい `claude-opus-5-5`。安くしたいときは `claude-sonnet-5-5`（約半額）や `claude-haiku-5-5`（約 40 分の 1）に変えられます
- 添削は、日記 1 つにつき 1 回です。同じ日記をもう一度添削することはありません
- AI がエラーになっても、日記は保存されます（先生ページで読めます）。生徒の画面に「もう一度ためす」ボタンが出ます
- 文法やフレーズの英作文で、教材の答えと合わなかった答えは、AI が正解かどうか判定し、まちがいの理由を書きます（上の「文法の単元とレッスン」）。同じ問題の同じ答えは、一度の判定を使い回すので、AI にたずねるのは 1 回だけです。1 人 1 日 100 回までです。1 回あたり、日記の添削よりずっと少ない料金です
- 日記の文章と文法の答えは、添削や説明のために Anthropic（米国）に送られます。生徒にも伝えておきましょう。データは Cloudflare のデータベースに保存されます

## 音声について

単語・例文・フレーズ・発音の文は、自然な AI の声（Cloudflare の Workers AI、Deepgram Aura）で読み上げます。

- 生徒が初めて 🔊 を押したときに、その文の音声を 1 回だけ作って保存します。次からは保存した音声をそのまま流すので、すぐ鳴ります。全員が同じ声で聞けます
- 音声の速さは「0.5・0.75・ふつう」から選べます。選んだ速さは、すべての 🔊 ボタンに使われ、生徒のスマホに保存されます
- 音声 AI は、Cloudflare の無料枠（1 日あたり、だいたい 3,700 文字ぶん。例文なら 70 文くらい）で作れます。保存した音声は何度流しても無料です
- 単語帳 Week 1 の音声はぜんぶで約 6,300 文字（無料枠 2 日ぶんくらい）、IELTS 語彙 Week 1・Week 2 はそれぞれ約 5,200 文字、LinkUp 英単語 Week 1 は約 5,000 文字。生徒が押した文から 1 回ずつ作られて、全員で共有されます
- 無料枠を使いきった日や、音声が作れなかったときは、スマホに入っている声で読み上げます（少し機械っぽい声）。次の日には、また自然な声で作れます
- 発音のお手本は、先生の録音（`public/pron/audio/`。Month 1 は 31 個で 1.2 MB、Month 2 は 30 個で 2.3 MB、Month 3 は 30 個で 1.4 MB）を流すので、無料枠は使いません。生徒は開いた文の 1 つ（30〜100 KB）だけを読みこみます。速さボタンも使えます
- 日記には読み上げはありません
- 声を変えたいときは、`wrangler.jsonc` の `VOICE` を変えます（例：`thalia`、`luna`、`asteria`、`apollo`。男性の声もあります）。Claude に頼んでも大丈夫です
- 設定は不要です。音声の保存場所（KV）も、初回のデプロイで自動で作られます

## 発音の録音について

生徒は自分の声を録音して、聞きなおせます（スマホの中だけで録音・再生します）。「完了して先生に送る」を押すと、その録音が先生に届きます。点数はつけません。

- iPhone は Safari、Android とパソコンは Chrome で録音できます。初めてのときに、マイクの許可を聞かれます。録音できないブラウザでは、お手本を聞いて「完了」だけ押せます（録音は届きません）
- 録音は 1 回 20 秒まで。1 文（3 秒くらい）で 10〜30 KB です。送るのは「完了」を押したときの 1 回だけなので、アプリが重くなることはありません
- 先生ページの「発音」タブで、Month ごとの完了の数と、届いた録音（新しい順）が聞けます。授業中にそのまま流せます。先生が追加した文の録音は、その文の下で聞けます
- 1 つの文に残るのは、最後に送った録音だけです（送りなおすと入れかわります）。保存先は Cloudflare の KV（音声と同じ場所）で、無料枠は保存 1 GB・書きこみ 1 日 1,000 回。生徒 6 人が 61 文ぜんぶ送っても 10 MB くらいなので、十分におさまります
- 生徒を削除すると、その生徒の録音も消えます
- 発音の文は、Month 1・2 が全員共通です。Month 1 は先生のシート「8月_発音課題」の 30 文（31 文目の It was really nice talking with you. Take care. は、1 か月 30 文にそろえるため外しました）、Month 2 は「7月_発音課題」の 30 文。Month 3 は「10月_発音課題」の 30 文で、先生が出した生徒だけに出ます（9 番のセルの下にある練習の単語は入れていません）。日本語訳・使う場面つきで、発音のコツは「つなげて読むところ（リンキング）」だけを書いています。Month 4 からも、シート（録音のリンクつき）を Claude に渡すと作れます
- 先生ページで生徒ごとに足した文は、生徒の画面では「先生が追加した文」に出ます

## 生徒ごとの発音課題の Month

発音課題の Month は全員共通ですが、生徒ごとに「どの Month を、どんな名前で出すか」を変えられます（先生ページの生徒の「設定・コード」→「発音課題の Month」、または生徒ごとのチャットの `pron-months` コマンド）。

- 例：Naomiさんは、もとの Month 1（旅行の文 30 文）だけを「Month 2」という名前で出しています。もとの Month 2 は出しません
- 例：もとの Month 2 を「Month 1」、もとの Month 3（10月）を「Month 2」という名前で出している生徒もいます
- Month を決めていない生徒には、Month 1・2 が出ます（Month 3 は出ず、一覧では「まだありません」）。Month 3 は、出したい生徒の設定に足します。全員に出す Month は `public/pron/phrases.js` の `USUAL_MONTHS` です
- 出さない Month は、発音の一覧に出ず、開いてもその一覧にもどります。「今日のやること」の発音とホームの進み具合も、その生徒の Month で数えます
- 完了と録音は、もとの Month のまま残ります（名前を変えても、続きから）。先生ページの発音タブでは「発音 Month 2（もとの Month 1）」のように出ます
- 変えた生徒には、まだない Month（準備中）も出ません

## アプリの前に終えていた発音課題

アプリを使う前に終えて先生に出していた発音課題は、生徒ごとのチャットから録音なしで「完了」にできます（`pron-done` コマンド。`docs/student-chats.md`）。

- 生徒の画面では、その文に「✅ 完了 ・ 先生に提出ずみ（アプリを使う前）」と出ます（日付は出ません）。あとでアプリで録音しなおすと、ふつうの完了（録音つき）になります
- 先生ページの発音タブでは「完了 30 / 30（うち 30 文はアプリを使う前に提出・録音なし）」のように出ます
- 日付はきのうまで。今日の「発音を1文 完了する」には数えません
- 完了にした Month は、生徒の発音の一覧で「✅ 完了」になり、ホームと今日のやることは次の Month から始まります
- まちがえたときは `--undo` でもどせます（もどるのは、こうして完了にした文だけ。生徒がアプリで完了した文は、そのまま）

## 今日のやることと勉強時間

- 毎日やることは「日記を書く」と「発音を1文 完了する」の 2 つです（単語と文法は入りません）。まだのものが、ホームのいちばん上に出ます。日付は日本時間で変わります
- 発音は、まだ完了していない最初の文（Month 1 → Month 2 → Month 3 の順）に進みます。1日に 2 文以上やってもかまいません
- 勉強時間は、アプリが画面に出ていて、3 分以内にタップやスクロールがあった時間を数えます（開きっぱなしで放っておいた時間は入りません）。だいたい 1 分ごとに保存します
- アプリ以外の勉強（本・動画・オンライン英会話など）は、生徒が「勉強時間」の画面で日ごとに記入します。アプリの時間がまちがっていたら、それも直せます
- 生徒の画面と先生ページの「勉強時間」タブに、上から次のものが出ます。どれも、上に期間（ボタン風）と合計・勉強した日数の色つきのタイル、下に「名前・横の棒・合計」の行が並ぶ同じ形です。今日・今週・今月の行はオレンジでめだたせています
  - アプリとアプリ以外の内わけやメモは、「詳細 ▾」を押すと出ます（はじめは閉じている。もう一度押すと閉じる）
  - 1 週間（月曜〜日曜）：その週の合計と勉強した日数、日ごとの行。生徒は日をタップすると、その日を記入・編集できる
  - 1 か月：その月の合計・勉強した日数・1日平均と、週ごと（第1週〜）の行。週をタップすると、上の 1 週間にその週が出る
  - これまでの合計（累計。アプリを使う前に入れた分もふくむ）：はじめた日、勉強した日数、月ごとの行。月をタップすると、上の 1 か月にその月が出る
- 生徒のホームの「勉強時間」には、今日・今週・これまでの合計が出ます。先生ページの生徒の画面の上にも、これまでの勉強時間が出ます

## うまくいかないとき

| こんなとき | 確認すること |
| --- | --- |
| 先生ページで「TEACHER_PASSWORD がまだ設定されていません」 | 手順 3 のシークレットが入っているか |
| 🔊 の声が、自然な声でなく機械っぽい声になる | その日の音声の無料枠を使いきったか、音声が作れなかった。Cloudflare の Worker の「Logs」で `tts error` を探す |
| 生徒の添削で「AI の設定に問題があります」 | `ANTHROPIC_API_KEY` が正しいか、Anthropic のクレジットが残っているか。本当の原因は `node scripts/teacher.mjs errors` の「くわしく」に出る |
| デプロイでデータベースのエラー | Cloudflare の「Storage & Databases」→「D1」で `hina-lessons` を作り、その ID を `wrangler.jsonc` の `d1_databases` に `"database_id"` として書く |

## 手元で動かす（開発用）

```sh
cd lessons
npm install
printf 'TEACHER_PASSWORD=test\n' > .dev.vars   # AI も試すときは ANTHROPIC_API_KEY=... の行を足す
npm run dev   # http://localhost:8787
```

データは `.wrangler/` の中のローカルのデータベースに入ります（本番とは別）。
