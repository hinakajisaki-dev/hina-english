# スモールトークのフレーズ教材

12週間でスモールトークができるようになるコースのフレーズ教材. 1週ごとに1ファイル.

| ファイル | 内容 |
| --- | --- |
| `week1.md` | Week 1「はじめて会った人と話す」#1〜49 |
| `week2.md` | Week 2「話題を広げて、気持ちよく会話を終える」#50〜100 |

md がもと. アプリのデータ（`lessons/public/phrases/weekN.js`）は、md を直したあとに作りなおす.

```sh
cd lessons
node scripts/smalltalk-to-js.mjs ../smalltalk/week1.md 1 "smalltalk/week1.md" > public/phrases/week1.js
node scripts/smalltalk-to-js.mjs ../smalltalk/week2.md 2 "smalltalk/week2.md" > public/phrases/week2.js
```

## フレーズを作るときのルール（先生の指定）

新しい週を作るときも、直すときも、このルールにそろえる.

### 1フレーズの中身

1. **フレーズ**：実際の日常会話で出てくる英語の文. 会話の流れの順番に並べる（質問 → 答え → 聞き返す → もう一歩深く聞く）. 1日7フレーズ前後
2. **和訳**
3. **塊**：そのフレーズで覚える形
4. **解説**：塊の意味と使い方
5. **例文**：塊を使ったもう1つの文（英語と和訳）
6. **瞬間英作文**：塊を使った問題を2問（日本語 → 英語）. 基本的すぎるもの・決まり文句はなし. 難しい単語や文の形には、わからないときに見るヒントをつける

### 塊はシンプルに

先生が直した塊がお手本. Week 2 の塊（What did you ＋ 動詞? / That sounds ＋ 形容詞 / so ＋ 形容詞 / work out など）は「シンプルで使いやすい」.

- 決まった英語 ＋ 入れかえる所1つ、くらいにする
- 「自分の答え ＋」「主語 ＋ is ＋ 形容詞」のような、説明のための言葉を入れない
- ( ) で「あってもなくてもいい部分」を書かない. 必要なら行を分ける
- 入れかえる所は「名詞」「名前」「内容」「文」など、ぱっとわかる言葉で
- `/` で区切らず、1つの形を1行に書く

| 前 | 先生が直したあと |
| --- | --- |
| How's ＋ 名詞 ＋ going? | How is 名詞?<br>How's 名詞? |
| 自分の答え ＋ How about you? | How about you? |
| 主語 ＋ is ＋ 形容詞, isn't it? | 内容, isn't it? |
| Nice to ＋ meet / see ＋ you | Nice to meet you<br>Nice to see you |
| call ＋ 人 ＋ 呼び名 | call me 名前 |
| work for ＋ 会社 / work at ＋ 場所 / work in ＋ 分野 | work for ＋ 会社<br>work at ＋ 場所<br>work in ＋ 分野 |
| since ＋ 始まった時 / for ＋ 期間 | since ＋ 始まった時<br>for ＋ 期間 |

### 解説は改行して読みやすく

- 内容が変わるところで改行する. だいたい1文1行
- 塊に形がいくつかあるときは、形ごとに例を1行ずつ添える（英語（和訳））

  ```
  どこで働いているかは前置詞で使い分ける.
  for のうしろは会社、at のうしろは場所、in のうしろは業界や分野.
  I work for Apple / Google（アップル・グーグルで働いています）
  I work at a café（カフェで働いています）
  I work in medicine / the food industry（医療業界・食品業界で働いています）
  ```

- 解説・例文には、瞬間英作文と同じ文を書かない（問題の答えになってしまうため）

### 句読点

- 解説の文の終わりは「。」ではなく「.」
- 』や」のあとには「。」も「.」もつけない
- 和訳と瞬間英作文の日本語は、文の最後に何もつけない（！と？はそのまま）. 2つの文に分かれるときは「.」で区切る
- 解説の中の例（英語（和訳））の行は、最後に何もつけない

## md の書き方

```
#### 9. I work for a travel company.
- 和訳：旅行会社で働いています
- 塊：
  - work for ＋ 会社
  - work at ＋ 場所
  - work in ＋ 分野
- 解説：
  - どこで働いているかは前置詞で使い分ける.
  - I work at a café（カフェで働いています）
- 例文：My sister works for a bank.（姉は銀行で働いています）
- 瞬間英作文①：病院で働いています → I work at a hospital.
- 瞬間英作文②：営業の仕事をしています → I work in sales.
  - ヒント：営業 ＝ sales
```

- 塊・解説は `  - ` の行が1行分. 1行だけの塊は `- 塊：How about you?` のようにそのまま書いてもいい
- 例文は「英語（和訳）」. 最後の（ ）の中が和訳になる
- 瞬間英作文がないときは `- 瞬間英作文：なし`
- `## Day N` が日、`### 場面N：…` が場面のまとまり、`#### 番号. フレーズ` が1フレーズ. 番号は週をまたいで通し番号
