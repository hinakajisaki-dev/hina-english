# Hina English サロン LP

オンラインサロン「Hina English」の紹介ページ。公開中（https://hina-english-salon.vercel.app/ 、Vercel・Root Directory `salon`）なのは **Stripe の審査に出した仮バージョン** です。いまは下の「本格版で必要なもの」をそろえて、お客さん向けの本番版にブラッシュアップしています。

| ファイル | 内容 |
| --- | --- |
| `index.html` | LP 本体 |
| `tokushoho.html` | 特定商取引法に基づく表記 |
| `privacy.html` | プライバシーポリシー |
| `character.png` | ひなのイラスト |
| `teacher-native.svg` / `teacher-japanese.svg` | 講師の仮キャラクター（写真が届くまでの代わり） |
| `og.png` | SNS・LINE でシェアされたときに出る画像 |

## 本格版で必要なもの

本番版のページには、写真の枠とプロフィールの仮枠（点線）が入っています。次をそろえて差し替えます。

- [ ] **ひなのプロフィール文**：経歴、英語との出会い、サロンをはじめた理由（講師セクションに入れる）
- [ ] **YouTube チャンネルの URL**：プロフィールの下に「YouTubeチャンネルを見る」リンクを置く
- [ ] **ライブと講義動画の写真 3 枚**：Zoom ライブ 2 枚、講義動画 1 枚。「ライブと講義動画の様子」セクションに入れる
- [ ] **講師の写真**：ネイティブ講師、日本人講師（いまは仮のキャラクター）。名前や紹介文を載せるかも決める
- [ ] **申し込みボタンの飛び先**：Stripe の決済ページの URL（いまはアプリのトップに飛ぶ）
- [x] **OGP 画像**：`og.png`（1200×630）と og:title などの設定。独自ドメインにしたら index.html の og:url / og:image を変える
- [ ] **AI の提供事業者名**：プライバシーポリシーの「外部サービスの利用」に、名前と所在国を書き足す

審査に出した仮バージョン（写真の枠なし）は、メインのブランチのコミット `3c2dfce` です。

- アプリ側で、解約予約中（期間の終わりまで active）のユーザーが使い続けられることを確認する
