## 本格版で必要なもの

審査用に、プロフィールや写真が必要な部分はいったん外しています。本格版では次をそろえます。

- [ ] **ひなのプロフィール文**：経歴、英語との出会い、サロンをはじめた理由（講師セクションに入れる）
- [ ] **YouTube チャンネルの URL**：プロフィールの下に「YouTubeチャンネルを見る」リンクを置く
- [ ] **ライブと講義動画の写真 3 枚**：Zoom ライブ 2 枚、講義動画 1 枚。「ライブと講義動画の様子」セクションに入れる
- [ ] **講師の写真**：ネイティブ講師、日本人講師（いまは仮のキャラクター）。名前や紹介文を載せるかも決める
- [ ] **OGP 画像**：SNS でシェアされたときに出る画像と、og:title などの設定
- [ ] **AI の提供事業者名**：プライバシーポリシーの「外部サービスの利用」に、名前と所在国を書き足す
