# 授業メモ

個人レッスンのあとに、先生が授業中のメモを整理して、その生徒のアプリに届けるしくみ.

## 流れ

1. 先生が授業中に Google ドキュメントにメモをとる（あえてまちがいを見せるところもある. 生徒は書きこまない）
2. その生徒用の Claude のチャット（「〇〇さん」）に、ドキュメントのリンクを送る
3. チャットが整理して、本文と、確認したいところを返す. 先生が直しを伝えて、できあがり
4. チャットがアプリに下書きで入れる（`docs/student-chats.md`）. 先生が「公開して」と言うと、生徒に届く（いまは生徒の画面に授業メモを出していないので、`lessons/public/course.js` の `NOTES_FOR_STUDENTS` を `true` にしてから）
5. 先生ページ → 生徒 → 「授業メモ」タブでも、同じメモを見たり、貼りつけて入れたりできる（「プレビュー」「下書き保存」「保存して公開する」）. 下書きは先生だけに見える
6. 生徒はホームの「📝 授業メモ」（勉強時間の上）から読める. 最後の「復習問題」は「内容を元に復習する」ボタンになり、単語カードのように1枚ずつ出る：英語（🔊）→ タップで意味と解説. 「復習タブに入れる」で、そのカードをフレーズ復習に入れられる. 瞬間英作文（英語を書く・言う問題）はない. 画面の下に出るので、メモを読みながら見られる

生徒ごとのチャットは、先生がその生徒用の内容を、ほかの生徒とは別に作るためのもの. 生徒が見たり書きこんだりはしない.
授業メモのほか、その生徒の単語・発音・文法の問題・日記のテーマ（先生ページの各タブに貼る形）も、そこで作れる.

## 整理のルール（先生の指定）

- 書いてあることをそのまま写さない. 授業の流れにそって、テーマごとのまとまり（`## 1. 〜`）に整理する
- 先生があえて見せたまちがいは、授業で教えた大事なものだけ「✗ まちがい → ○ 正しい文（短い理由）」で残す
- 大文字・小文字のまちがいは指摘しない. だまって直す
- 日常会話なら気にならない小さなまちがい（When I want eat など）は指摘しない. 正しい文だけを書く
- 授業中に一緒に考えた「日本語 → 英語」の問題は、**問題**・**答え**・**ほかの言い方**・1文ずつのポイントに分ける
- 授業で広げた文法・表現（am going to と will のちがい、When I 〜 など）は、使い方の説明と例文にまとめる
- 明らかな打ちまちがいはだまって直す. 迷ったところは「確認したいところ」として先生に聞く（本文には入れない）
- 最後に「## 復習問題」：授業で出たフレーズ・文から 8〜12 こ. 英語・意味・短い解説（使い方や、覚えるポイントを1行で）

## 本文の書き方

アプリ（`lessons/public/notes/format.js`）はこの書き方を読んで表示する.

```
## 1. 英作文：日曜日のこと（日本語 → 英語）
**問題**：日曜日に家族と海へ行きました。
**答え**：I went to the beach on Sunday with my family.

## 2. 文法：very little / very few
| | 数えられない | 数えられる |
| --- | --- | --- |
| とても少ない | very little | very few |

- very few：I have very few cushions.
  - ✗ I have very little shoes. → ○ I have very few shoes.（shoes は数えられる）

## 復習問題
| 英語 | 意味 | 解説 |
| --- | --- | --- |
| I have very few shoes. | 靴はとても少ししか持っていません | 数えられる名詞には very few（数えられないものは very little） |
```

- `## ` まとまりの見出し、`### ` 小見出し
- `**…**` 太字
- `- ` 箇条書き. スペース2つ下げると1段下. 箇条書きの下にスペースで下げて書いた行は、その項目のつづき
- 表は `| … |` の行のあと、2行目に `| --- | --- |`
- 空の行で段落を分ける. `---` は区切り線
- ✗ と ○ は、うしろにスペースがあるときだけ赤・緑のしるしになる（`〇〇したい時` のような ○ はそのまま）
- `# ` の大見出しは書かない（タイトルと授業の日は、アプリの入力らん）
- いちばん最後に `## 復習問題` と `| 英語 | 意味 | 解説 |` の表. 表としては見せずに、カードのボタンになる. 解説はなくてもいい（前の `| 日本語 | 英語 |` の表も、そのまま読める）
- チャットのコードブロックの ``` の行ごと貼っても大丈夫（その行は読みとばす）
