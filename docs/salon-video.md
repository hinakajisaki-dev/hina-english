# サロン動画の編集

先生が撮った動画とスライドから、サロン用の文法解説動画を作るときの決まり。
お手本は「冠詞動画-1〜3」（いちばんのお手本は 3）。数字は、冠詞動画-3 を測ったもの。

## 素材

- 顔だけの動画（iPhone・横向き・1920×1080・30fps）
- スライドの PDF（16:9）
- 先生がそのつど Google ドライブのリンクで送る
- **リンク・動画・SE の音は、このリポジトリに入れない**（公開リポジトリのため）

## 進め方

1. 素材が届いたら、**最初の1分だけ見本**を作って先生に見せる
2. OK をもらってから、全部を作る
3. 文字起こしは ElevenLabs（`/v1/speech-to-text`）を使う

## 画面

| 場面 | 作り |
| --- | --- |
| 冒頭（約45秒）と最後 | 左にタイトルのスライド（x 0〜1149）、右に顔（x 1150〜1919）。カットごとに顔の大きさを少し変える |
| 本編 | スライドを全画面、右上に丸い顔 |
| スライドから離れた話 | 顔だけを全画面（冠詞動画-2 にある） |

- 丸い顔：中心 (1697, 185)、外側の半径 154px、ピンクの縁 約10px（`#EEAFCC`）
- スライドの順番どおりに出す。話していないスライドは出さなくていい

## カット

- **間と言い直しを消す**。順番は変えない。速さも変えない
- 間は、ほとんど 0.4秒以下。長くても 0.75秒。カットした所の間は 0.1秒ほど
- 切り替えは全部パッと切り替える。フェードは使わない（最初と最後も）
- めやす：素材 33分 → 21分半（192か所をカット）

## 赤い強調

- 赤い角丸の枠、赤い下線、1語を囲む赤い丸
- **いま話している所に1つだけ**。動かさず、パッと出す
- 出た瞬間に SE「ポピ」を鳴らす

## テロップ

| 種類 | 見た目 | 使う所 |
| --- | --- | --- |
| ふつう | 白い文字＋紫ピンクの縁（`#D800E0` くらい）＋影 | 大事な言葉 |
| キーワード | 黄色い文字＋白い縁＋黒い影 | 「無冠詞」「複数形」など、少しだけ |
| 例文 | ふつうと同じ。**間違いの語だけ赤**（`× I like a dogs.`）。正しい文は `○` | ×・○ の例文。出た瞬間に SE「ポン」 |

- 太い丸ゴシック。画面の下・中央。1行が基本（長い時は2行で小さく）
- **全部の言葉には付けない**。冒頭はほぼ全文。本編は、スライドに無い大事な言葉だけ（例文・言いかえ・クイズ・まとめ・ひとこと）
- 言葉はほぼ話したまま。「はい」「えー」は落とす
- 1個 1〜9秒（まんなかは 3.4秒）。パッと出て、パッと消える
- めやす：21分半で 131個（画面に出ている時間は全体の 37%）
- 最後は `See you guys in the next video!` と `また次の動画でお会いしましょう` の2行

## SE（先生の指定・2026-11-12）

マンネリ化しないように、赤い所を出す時などに入れる。BGM は入れない。

| 何が出た時 | SE | 使う音 |
| --- | --- | --- |
| 赤い線・赤い枠 | ポピ | 冠詞動画-3 の 13:44.64 から 0.205秒を切り出す（声と重なっていない所） |
| 赤いテロップ（×・○ の例文） | ポン | 先生の SE フォルダから近い音を選び、見本で先生に聞いてもらって決める（仮：`決定ボタンを押す31.mp3`） |
| タイマー表示（問題を出す場面。多くない） | パッ | 先生の SE フォルダの `パッ (1).mp3` |

- ポピは「低い音 → 高い音」の2音（約1000Hz → 約2000Hz）。冠詞動画-3 では約75回、ポンは約15回
- お手本のポピ・ポンは、先生の SE フォルダの音とは別の音（前の編集で使われた音）
- タイマーの見た目は、お手本（冠詞動画-1〜3）に無い。問題の場面が来たら、見本で先生に案を見せる

## 音と書き出し

- 声の大きさは −14 LUFS くらいにそろえる
- 1920×1080・30fps・H.264（5〜9Mbps）・AAC 48kHz ステレオ
