# L と R の発音｜講義動画 台本（第1稿）

- サロンの講義動画
- 長さの目安：約12〜15分（セリフ約3,700字＋実演・リピートの間）
- 話す人：ひな
- 【実演】はひなが発音して見せるところ、【リピート】は視聴者に声に出してもらうところ（少し間をあける）

---

## 1. 考え方：日本人が L と R で意識するポイント

### なぜ難しいのか

- 日本語の「ら行」は、L でも R でもない音。舌先で上の歯ぐきを**一瞬はじく**音
- 英語では L と R はまったく別の音。light（光）と right（右）、rice（お米）と lice（シラミ）のように、意味が変わる
- 「ら行」のまま話すと、どっちつかずの音に聞こえる。だから「はじく」をやめて、新しい舌の動きを2つ覚える必要がある

### 3つの舌の動き

| 音 | 舌先 | ひとことで |
| --- | --- | --- |
| **L** | 上の前歯の裏（付け根の歯ぐき）に、しっかりつけたまま | つける |
| 日本語の「ら」 | 歯ぐきを一瞬はじいて、すぐ離れる | はじく |
| **R** | どこにもつけない。舌を奥に引いて、口の中で丸める | つけない |

### L のポイント

1. 舌先を、上の前歯の裏〜付け根の歯ぐきにつける
2. つけたまま声を出す（声は舌の両わきから出る）
3. はじかない。少し「ためて」から、次の母音へ離す

- コツ：小さい「ン」から入るイメージ →「（ン）ライト」
- チェック：鏡で舌先が上の歯の裏についているのが見える／「lllll」と伸ばせる

### R のポイント

1. 舌先はどこにもつけない（いちばん大事）
2. 舌を奥に引いて、口の中で丸める。舌の両わきは上の奥歯に軽くふれる
3. 唇を少しすぼめる（「ウ」の口）

- コツ：小さい「ゥ」から入るイメージ →「（ゥ）ライト」
- チェック：鏡で舌先が見えない・唇が丸い／「rrrrr」と伸ばせる

### 伸ばしチェック

L も R も、子音のまま**伸ばせる**音。日本語の「ら」は一瞬ではじく音なので伸ばせない（伸ばすと「あー」になる）。
伸ばしている途中で「ら」っぽくなったら、舌がはじいている合図。

### 練習のしかた＝筋トレ

- 発音は「知識」ではなく「筋トレ」。分かっただけでは言えない。回数で言えるようになる
- お手本をまねする → 録音して比べる → 直す、をくり返す
- 最初はおおげさに、ゆっくり → だんだん自然なスピードへ
- 週1回1時間より、毎日5分
- 順番：伸ばす（子音だけ）→ 母音とつなげる → ペア単語 → 文

## 2. 台本

### シーン1　オープニング（0:00〜1:00）

**画面**：タイトル「L と R の発音」／"I love rice." と "I love lice." を並べる

こんにちは、ひなです！
今日は、日本人がいちばん苦手と言ってもいいかもしれない、**L と R の発音**をやっていきます。

さっそくですが、ちょっとクイズです。
「お米が大好き！」って英語で言うと、"I love rice." ですよね。
でも、もし R がちゃんと言えていなくて、L の音になってしまったら……
"I love lice."
lice は「シラミ」。つまり、「シラミが大好き！」に聞こえちゃうかもしれないんです（笑）

実際の会話では、話の流れで分かってもらえることも多いです。
でも、自分で言い分けられるようになると、話すときの自信が全然ちがいます。
それに、自分で言える音は聞き取りやすくもなるので、リスニングもラクになります。

今日は、
1つめ、なんで日本人にとって L と R は難しいのか
2つめ、L と R の舌の位置
3つめ、毎日5分でできる練習メニュー
この3つをやっていきます。
最後まで、一緒に声に出してやってみてくださいね！

### シーン2　なんで難しいの？（1:00〜2:30）

**画面**：L・ら・R の3つを並べた図（つける／はじく／つけない）

まず、なんで日本人は L と R が苦手なのか。
理由はシンプルで、日本語の「ら行」は、**L でも R でもない音**だからなんです。

ちょっと「らりるれろ」って言ってみてください。
【リピート】らりるれろ

……舌の先が、上の歯の裏のあたりに「ペッ」と一瞬当たって、すぐ離れていませんか？
日本語の「ら」は、舌先で**一瞬はじく音**なんです。

英語の L と R は、どちらもこの「はじく」動きをしません。
L は、舌先をしっかり「**つける**」。
R は、舌先をどこにも「**つけない**」。
日本語の「ら」は、そのちょうど間の「**はじく**」。

だから、日本語の「ら行」のまま英語を話すと、L にも R にもならない、どっちつかずの音に聞こえてしまうんです。

逆に言うと、やることはハッキリしています。
「はじく」のをやめて、「つける」と「つけない」の2つの動きを覚えればいい。
それだけです！

### シーン3　大事な前提：発音は筋トレ（2:30〜4:00）

**画面**：「発音は筋トレ」の見出し＋3つのルール（まねする／おおげさに・ゆっくり／毎日ちょっとずつ）

舌の位置の説明に入る前に、ひとつだけ、大事なことをお伝えさせてください。
それは……**発音は「筋トレ」**だということです。

舌って、じつは筋肉のかたまりなんです。
そして私たちは、生まれてからずっと、日本語の「ら行」の動きを毎日くり返してきました。
もう、体にしみついているんですね。

筋トレって、正しいフォームを知っただけでは、筋肉はつかないですよね。
実際に何回も体を動かして、はじめて筋肉がついてくる。
発音もまったく同じです。
今日の動画で「L は舌をつける、R はつけない」と分かっても、それだけではまだ言えるようにはなりません。
「分かる」と「できる」は、別物なんです。

じゃあ、どうすればいいか。ポイントは3つです。

**1つめ、まねをする。**
赤ちゃんも、まわりの人の言葉をまねして話せるようになりますよね。
お手本の音をよく聞いて、そっくりまねする。これがいちばんの近道です。

**2つめ、最初はおおげさに、ゆっくり。**
筋トレも、最初はゆっくり、正しいフォームでやりますよね。
発音も、最初は「やりすぎかな？」くらいおおげさに、ゆっくりで大丈夫。
慣れてきたら、だんだん自然なスピードにしていきます。

**3つめ、毎日ちょっとずつ。**
週に1回1時間やるより、毎日5分のほうが効きます。
この動画の最後に、毎日5分でできる筋トレメニューを用意しているので、ぜひ使ってください。

練習していると、舌や口のまわりがちょっと疲れてくると思います。
それは、ふだん使っていない筋肉を使っている証拠。いい感じです！

### シーン4　L の発音（4:00〜6:00）

**画面**：L の舌の位置のイラスト（舌先が上の前歯の裏についている）＋ポイント3つ

それでは、まず **L** からいきましょう。
ポイントは3つです。

**1つめ。** 舌の先を、上の前歯の裏、歯の付け根の歯ぐきのあたりにつけます。
**2つめ。** つけたまま、声を出します。
**3つめ。** はじかないこと。日本語の「ら」みたいに、ペッとすぐ離さないでください。

じゃあ、一緒にやってみましょう。
舌の先を上の前歯の裏につけて、そのまま声を出します。
【実演】lllll（舌先をつけたまま、こもった声を伸ばす）
【リピート】lllll

鼻歌みたいな、こもった音が出ていれば OK です。
このとき、声は舌の両わきから出ています。

次に、そこから舌を離して「ア」につなげます。
【実演】lllll……la ／ la, la, la
【リピート】la, la, la

ゆっくりでいいので、舌先をつけて、ちょっとためてから離す。これが L です。

コツは、最初に小さい「ン」を入れるイメージ。
light なら「（ン）ライト」。
舌先をつけた状態から始まるので、自然と L の音になります。

単語でやってみましょう。私のあとに続いて言ってください。
【実演】【リピート】light ／ love ／ look ／ play ／ glass

L ができているかのチェック方法は2つあります。
**鏡チェック**：L を言っているときに鏡で口の中を見ると、舌先が上の歯の裏についているのが見えます。
**伸ばしチェック**：L は「lllll」と伸ばせる音です。伸ばせなかったら、舌がはじいてしまっている合図です。

### シーン5　R の発音（6:00〜8:00）

**画面**：R の舌の位置のイラスト（舌が奥に引いて丸まっている・唇が丸い）＋ポイント3つ

次は **R** です。
R のポイントも3つ。

**1つめ。** いちばん大事なのは、舌先を**どこにもつけない**こと。上あごにも、歯にも、どこにもつけません。
**2つめ。** 舌を奥にグッと引いて、口の中で丸めます。舌の両わきが、上の奥歯に軽くふれるくらいです。
**3つめ。** 唇を少しすぼめます。「ウ」の口ですね。

一緒にやってみましょう。
唇を「ウ」の形にして、舌を奥に引いて、そのまま声を出します。
【実演】rrrrr（口の奥でうなるように伸ばす）
【リピート】rrrrr

犬がうなっているような、口の奥でこもった音が出ていれば OK です。

そこから「ア」につなげます。
【実演】rrrrr……ra ／ ra, ra, ra
【リピート】ra, ra, ra

コツは、最初に小さい「ゥ」を入れるイメージ。
right なら「（ゥ）ライト」。
唇をすぼめて「ゥ」から入ると、舌が上あごから離れたままになるので、R の音になりやすくなります。

単語でいきましょう。私のあとに続いて言ってください。
【実演】【リピート】right ／ red ／ rice ／ pray ／ grass

R のチェックも同じく2つ。
**鏡チェック**：R のときは舌が奥に引っこんでいるので、舌先が上の歯の裏についていません。唇も少し丸くなっています。
**伸ばしチェック**：R も「rrrrr」と伸ばせる音です。途中で舌が上あごに当たって「ら」っぽくなったら、もう一度、舌を奥に引いてやり直しましょう。

### シーン6　L と R を比べてみよう（8:00〜9:30）

**画面**：L・R のペア単語6組（意味つき）

では、L と R を並べて練習してみましょう。
もう一度おさらいです。
L は、舌先を「つける」。
R は、舌先を「つけない」。奥に引いて丸める。
日本語の「ら」の「はじく」は、今日は封印です！

ペアになっている単語を、L → R の順番で言っていきます。
最初はゆっくり、おおげさに。

【実演】【リピート】
- light（光）／ right（右）
- lice（シラミ）／ rice（お米）
- glass（グラス）／ grass（草）
- play（遊ぶ）／ pray（祈る）
- long（長い）／ wrong（まちがった）
- fly（飛ぶ）／ fry（揚げる）

glass や play みたいに、L や R の前に別の子音があるときは、「グ・ラス」「プ・レイ」と間に「ウ」を入れないのがポイントです。
g の口のまま、すぐ L につなげる感じで言ってみてください。

L のときは舌先がペタッとついて、R のときは舌が奥に引っこむ。
この切りかえを、口の筋肉に覚えさせていきます。

もう一回、今度は少しスピードを上げて。
【実演】【リピート】（同じ6組を、ふつうのスピードで）

### シーン7　文で練習（9:30〜10:30）

**画面**：3つの文（L と R に色分け）＋日本語訳

単語ができたら、次は文です。
文になると、ほかの音にまぎれて、つい日本語の「ら」に戻りがち。ここもゆっくりからいきましょう。

**1. I love rice.**（お米が大好き）
love の L は舌をつける、rice の R はつけない。オープニングの文ですね！
【リピート】

**2. Turn right at the light.**（その信号を右に曲がって）
right と light が1つの文に入っています。道案内でそのまま使えます。
【リピート】

**3. I really like it.**（ほんとに気に入ってる）
really は、R と L が1つの単語に入っている、ちょっと難しい単語。
最初は舌を奥に引いて R、すぐに舌先を前歯の裏につけて L。舌が「奥 → 前」に大きく動きます。
チャレンジしてみてください。
【リピート】

それぞれ、ゆっくり → ふつうのスピードで、もう一度。
【実演】【リピート】

### シーン8　毎日5分の筋トレメニュー（10:30〜11:30）

**画面**：5つのメニュー（時間つき）。「スクショしてね」

最後に、毎日5分でできる、L と R の筋トレメニューです。
スクショしておいてくださいね。

1. **伸ばす（1分）**：L を5秒、R を5秒。これを交互に3セット
2. **母音とつなげる（1分）**：la – ra ／ li – ri ／ lu – ru ／ le – re ／ lo – ro
3. **ペア単語（1分半）**：今日の6組を、ゆっくり → ふつうのスピードで
4. **文（1分）**：3つの文を、お手本をまねして3回ずつ
5. **録音チェック（30秒）**：1文だけスマホで録音して、お手本と聞き比べる

お手本の音は、この動画の私の声でもいいし、辞書アプリの発音ボタンでも OK です。
大事なのは、まねして、くり返すこと。
最初の1週間は「ちゃんとできてるのかな？」って思うかもしれません。
でも、筋トレと同じで、続けているうちに、ある日ふっと言えるようになります。

### シーン9　エンディング（11:30〜12:00）

**画面**：まとめ3行（L＝つける／R＝つけない・引いて丸める／発音は筋トレ）＋ひなのキャラクター

今日のまとめです。
**L** は、舌先を上の前歯の裏に「つける」。
**R** は、舌先を「つけない」。奥に引いて丸めて、唇は「ウ」。
そして、**発音は筋トレ**。まねして、毎日ちょっとずつ。

ライブでは、みなさんの発音を実際に聞いてアドバイスできるので、ぜひ「L と R、練習してきました！」って声をかけてくださいね。
それでは、今日も一緒にがんばりましょう。See you!
